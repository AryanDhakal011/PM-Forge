PMForge Portfolio Section — Final Complete HandoffDocument Status: Production-ready single source of truth.

Purpose: Turn interview practice into credible, recruiter-ready career artifacts while solving the three real-world failure modes that kill most PM portfolios.0. Non-Negotiable Principles
Simulated work is never presented as production impact. It is framed as Strategic Teardown & Stress Test.
Every case study has three reading depths by default. The 15-second view is the primary surface.
LinkedIn ingestion never depends on fragile scraping or restricted OAuth scopes.
AI never invents experience. It only synthesizes, rewrites, or anonymizes what the candidate already owns.
Public profiles default to private/draft. Explicit promotion + checklist required before anything goes live.
The portfolio must survive a 6–10 second recruiter scan and still reward a 5–10 minute hiring-manager deep dive.

Primary path: User downloads LinkedIn PDF (More → Save to PDF) and drops it. System parses experience, bullets, dates, skills, summary, education with high fidelity.
Secondary: Public profile URL (best-effort, rate-limited, graceful degradation).
Tertiary: Raw text paste with automated field detection.
Output: Master Profile data model that feeds Strength score, resume, case studies, and public profile.
2.2 Living PM Profile (Public or Private)
Hero: Name, target title, one-line value prop, domain focus, open-to-work status.
About / Philosophy (AI-assisted draft from Master Profile, fully editable).
Selected Case Studies (user chooses which appear publicly).
Impact Highlights strip.
Skills & Frameworks with evidence links.
Contact / CTA.
Default state = Draft. Publishing requires explicit checklist confirmation.
2.3 Multi-Depth Reading Engine (Mandatory for every case study)Floating toggle on every case study page/card:
Level 1 – 15-Second Exec Skim (default for public visitors)
Clean visual card: Problem Statement · Single Key Metric Moved/Defended · Primary Strategic Trade-off · Methodology/Tech Stack.
Level 2 – 2-Minute Narrative
Standard structured flow (Context → Hypotheses / Options → Friction & Trade-offs → Decision → Outcomes → Learning).
Level 3 – Artifact Deep Dive
Full decision record, decision trees, calculation scratchpads, PRD excerpts, spoken audio snippet (if available), original Interview evidence links.
Frontend simply toggles visibility layers and layout. All three levels live in the same data object.2.4 Case Study System
Import path from any completed Interview scenario → pre-fills problem, evidence, decision, trade-offs, metrics, guardrails, learning. Auto-labeled [Strategic Teardown & Stress Test].
Manual builder for real work → labeled [Production Impact].
AI assists with narrative polishing, metric framing, ownership language, and missing-element detection. Never invents facts.
Visual artifact upload (screenshots, simple diagrams, charts) with NDA warnings.
2.5 Embedded Decision Replay + Verifiable Voice SnippetsFor any case study originating from a PMForge Interview:
Interactive 45–60 second micro-player showing:
Initial Metric / Situation
Pushback or Injected Constraint
Trade-off Chosen
Candidate’s spoken rationale (audio)

Subtle verification badge: “Verified Simulation — Defended under timed pressure on PMForge”.
Optional Top-X% signal if the candidate scored in the upper band on the relevant dimension.
This turns practice into authentic proof of real-time reasoning under pressure.2.6 “Ask This Candidate” Portfolio AI Agent
Discrete inquiry bar on public profile: “Ask an interview question about [Name]’s work.”
Visitor asks natural questions (e.g., “How do they handle engineer pushback?”, “Any experience with B2B churn?”).
RAG agent grounded strictly in the candidate’s published case studies, resume bullets, and decision records.
Response always cites the exact artifact: “Yes. In their B2B Billing Migration case study… [Read Case Study →]”.
If no relevant experience exists: “Alex hasn’t documented an experience with this specific challenge yet. Invite them to interview to learn more.”
Zero hallucination policy. Agent refuses to invent.
2.7 NDA Metric Masking & De-Risking Scrubber
Client-side tool.
Candidate pastes sensitive text → one-click “De-Risk & Anonymize”.
Converts absolute numbers and internal names into relative lifts, order-of-magnitude impact, and generic descriptors while preserving mathematical consistency across the entire portfolio.
Maintains an internal mapping dictionary so percentages stay coherent.
2.8 AI-Powered Resume / CV Builder
Master + role-specific versions.
Strict single-column, semantic HTML-to-PDF templates (ATS-safe). No multi-column CSS grids.
AI rewriting and tailoring limited to data present in Master Profile or Interview Decision Records.
JD Match Differential (not just a score):
Hard Requirements missing
Impact-type mismatch (e.g., “JD wants Zero-to-One, your resume is 80% Optimization”)
Suggested additions drawn only from existing evidence

Cover letter companion that references one real portfolio case study.
Export: PDF, Markdown, plain text. Version history retained.
2.9 Skills & Evidence Map
Explicit skills inventory.
Each skill links to supporting case studies, Interview scores, or resume bullets.
Gap analysis against target role types (Growth, AI, Platform, Consumer, etc.).
2.10 Strength Dashboard & Goals
Composite Profile Strength score.
Dimension breakdown + prioritized next actions.
Career goals + lightweight job tracker (save JD → create tailored resume version → link relevant case study).
Practice recommendations tied to weakest portfolio signals.
