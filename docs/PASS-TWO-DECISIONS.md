1. Keep one production preview on localhost:3002, with a localhost-only, fictional Gemini free pilot; local admission ceilings are not claimed to be Google account quotas. No paid provider or billing is enabled.
2. Preserve the handoff scenes using SVG, finite CSS motion and the existing GSAP/Lenis foundation. Long pinned scroll traps, continuous shaders, custom drag inertia and fake listening/clipboard demonstrations are replaced by readable, keyboard-operable interactions; no new runtime dependency is added.
3. Complete the Career Studio decision-record loop on the existing Dexie/SQLite architecture. Use additive optional fields, one Proof selector, immutable resume snapshots, one-case publishing, hidden contact by default, explicit media consent, local redaction and a private single-file backup including blobs.

## Implementation notes

The Subframe MCP inspiration search selected The Vessel (https://vessel-magazine.no/) for editorial rhythm, generous gutters, warm paper and large serif contrast. PMForge keeps its forest/cream/amber identity; no reference assets were copied.

Landing: responsive casebook and reactive chart; stampable desk with contextual notes; three operable practice scenes; colored intent doors; skill/time chips; a stateful three-step tour; illustrative project vignettes; a deeper paper artifact; local control-panel demonstrations; a calm clock closing. Mobile navigation remains one tap rather than requiring a second tap after a door animation. Paper folding and a decision rule mark app arrival; navigation feedback never adds an artificial wait.

Career Studio: nine-section builder and shared reading renderer; metric certainty and ownership labels; transparent quality checks; autosave and leave-before-debounce protection; local opaque image redaction (stronger than a reversible blur); local evidence captions; native drag with a keyboard/touch stage menu; stage history and closing reasons; deterministic JD skill mapping; explicit publish preflight and preview; handle availability, 30/90/180-day expiry and default noindex; typed revocation; opt-in aggregate depth events. Existing local PDF parsing, immutable resumes and optional source audio remain. Original user data is not destructively migrated.

A JSON studio backup carries media as base64 in one file rather than adding a zip dependency. It is limited to 50 MB and includes private publishing keys; the UI tells the user to keep it private. Local redaction replaces the flattened copy after explicit Apply; original files on disk are not modified.

The handoff marks DOCX, password protection, advanced analytics, custom domains, a full story bank, mentor-review workflow expansion and text version history as later tiers. Those are not represented as completed features. Existing signed mentor review endpoints are retained. No invented social proof, automated job applications or external messages are introduced.

## Launch boundaries

Blocked by missing public operator identity/privacy contact and domain/email configuration, owned by the PMForge owner, requiring the hosting configuration and legal review before public launch. Physical Safari/Firefox/iOS/Android testing and expert review remain separate from Chromium automation. No mocked result or one live reply establishes sustained p95 or capacity.
